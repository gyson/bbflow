bbflow 0.0.10 adds commands for setup scripts and saves changes in Settings
automatically.

## What changed

- Use `bbflow tool list`, `bbflow tool add`, and `bbflow tool remove` to manage
  saved tools from a script. Run `bbflow tool add` again with the same tool name
  to update its commands.
- Use `bbflow settings get` and `bbflow settings set` to read settings or set
  the appearance, default tool, worktree mode, or starting branch or commit.
  The tool and settings commands require a running server.
- Settings saves selections and checkboxes when you change them. Text fields
  save when they lose focus. The heading shows the save status.
- The sidebar and browser icon show a rainbow pixel logo. The macOS menu bar
  uses the same shape in one color.
- The README has shorter installation and first-use instructions. The command
  reference describes the new commands and their options.
- This release removes `bbflow migrate`. If you still need to copy history from
  the original app, follow the [0.0.9 migration instructions](https://github.com/gyson/bbflow/releases/tag/v0.0.9)
  before you upgrade.

## Upgrade from 0.0.9

Run `bbflow update` to replace the executable. Active sessions continue until
you restart the server. When you are ready to stop them, run these commands:

```sh
bbflow server restart
bbflow ui
```

The SQLite format stays at 8. Existing sessions, recordings, settings, and
drafts remain available.

## Install

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
```

Run `bbflow server start` and `bbflow ui` to open bbflow.

## Release checks

The Release workflow runs `make test`, `make check`, `make web-check`, and a
native release smoke check on Apple Silicon and Intel before it publishes the
archives.
