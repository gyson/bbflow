bbflow 0.0.11 adds automatic session titles and Markdown previews in the workspace.

## What changed

- Choose Claude, Codex, or Code Puppy under **Automatic titles** in Settings.
  To make a title, the selected tool sends your first editor message to its provider.
  Automatic titles start off and apply to new sessions.
- Open **Preview** in **Changes** or **Files** to read a rendered Markdown file.
  The preview supports tables and task lists. It shows placeholders for images.
- Use **Show more** to see more sessions in a project. Long entries in
  **Sent messages** start folded and can expand in steps.
- Use **Add tool**, **Save**, and **Cancel** to manage tool edits in Settings.
  **Continue in new terminal** uses the selected tool's startup command.
  If a setup script gives `bbflow tool add` a separate continue command, remove that
  argument before you run the script again.
- The session header uses shorter worktree labels and simpler terminal controls.
- Contributors can seed a separate demo instance and run a two-session pull request
  review loop in Codex or Claude Code.

## Upgrade from 0.0.10

Run `bbflow update` to replace the executable. Active sessions continue until
you restart the server. When you are ready to stop them, run these commands:

```sh
bbflow server restart
bbflow ui
```

The server upgrades SQLite format 8 to format 10 on startup. It keeps recorded
history, drafts, and existing titles. The upgrade removes saved continue commands and
keeps startup commands.

## Install

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
```

Run `bbflow server start` and `bbflow ui` to open bbflow.

## Release checks

The Release workflow runs `make test`, `make check`, `make web-check`,
`make skill-check`, and a native release smoke check on Apple Silicon and Intel
before it publishes the archives.
