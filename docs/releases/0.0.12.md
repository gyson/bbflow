bbflow 0.0.12 fixes a server crash when a terminal becomes narrower.

## What changed

- Resizing a terminal with full scrollback no longer crashes the server or stops
  every session. The terminal keeps the newest output and drops rows beyond its
  scrollback limit.
- If another terminal emulator panic occurs, bbflow logs the error and resets only
  that terminal's rendered screen. The process continues, and the archive keeps its
  original recording. A reset clears the rendered screen, scrollback, and terminal
  modes.
- The same protection applies when bbflow reads a stored terminal recording.

## Upgrade from 0.0.11

Run `bbflow update` to replace the executable. Active sessions continue until
you restart the server. When you are ready to stop them, run these commands:

```sh
bbflow server restart
bbflow ui
```

The SQLite format stays at 10. Existing sessions, recordings, settings, and
drafts remain available.

## Install

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
```

Run `bbflow server start` and `bbflow ui` to open bbflow.

## Release checks

The Release workflow runs `make test`, `make check`, `make web-check`, and
`make skill-check` on Apple Silicon and Intel. Each runner also performs a native
release smoke check before publication.
