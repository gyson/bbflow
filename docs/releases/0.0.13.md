bbflow 0.0.13 can restart the selected server and open its web UI when you update bbflow.

## Upgrade from 0.0.12

Run `bbflow update` to install 0.0.13. The 0.0.12 updater leaves the running
server and its sessions active. When you are ready to end those sessions,
run these commands from a terminal outside bbflow.

```sh
bbflow server restart
bbflow ui
```

If you use a custom instance directory, add `--dir DIR` before `server` and
`ui`. This release uses SQLite format 10 and keeps your history, settings,
and drafts.

## What changed

- Starting with 0.0.13, `bbflow update` asks for confirmation when an update
  is available and the selected server is running. After you confirm, bbflow
  downloads and verifies the release. It then restarts that server, ends its
  active sessions, and opens the new web UI. Other instances keep running.
- For unattended updates, use `bbflow update --yes` to accept the restart.
  If the selected server is stopped, the command only replaces the executable.
- If the server is shutting down, `bbflow server start`, `stop`, and `restart`
  now wait up to 15 seconds for it to release the archive.
- Each new macOS server starts the menu bar companion. Remove `--no-menubar`
  from scripts that call `bbflow server start` or `bbflow server restart`.

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
