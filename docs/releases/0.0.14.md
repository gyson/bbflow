bbflow 0.0.14 adds a storage report and makes it easier to review files and changes.

## What changed

- Run `bbflow storage` to see archive size and estimated storage use by project,
  session, event kind, and day. Event counts are exact. Use `--redact` to replace
  project names and session titles with short IDs in the Markdown report.
  [Command reference](https://github.com/gyson/bbflow/blob/v0.0.14/docs/COMMANDS.md#storage-report)
- In **Changes**, use **Compare with** to select a recent commit. The diff includes
  that commit, later commits, and uncommitted changes.
  [Changes pane](https://github.com/gyson/bbflow/blob/v0.0.14/docs/SPEC.md#changes-pane)
- Drag the divider in **Files** or **Changes** to resize the file list. Both views
  use the same width.
- File and diff views highlight Markdown headings, links, quotes, and code blocks.
  Dark mode uses more saturated syntax colors.
- When you start a managed worktree from a remote-tracking branch such as
  `origin/main`, bbflow fetches that branch first. If the fetch fails and a local
  copy exists, bbflow uses it and shows a notice.
  [Worktrees](https://github.com/gyson/bbflow/blob/v0.0.14/docs/SPEC.md#session-preparation-settings-and-worktrees)

## Upgrade from 0.0.13

Run `bbflow update` from a terminal outside bbflow. If the selected server is
running, the command asks before it restarts the server and ends its active
sessions. The SQLite format stays at 10. Your history, settings, and drafts
remain available.
[Update command](https://github.com/gyson/bbflow/blob/v0.0.14/docs/COMMANDS.md#update-bbflow)

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
