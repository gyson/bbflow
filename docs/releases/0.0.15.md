bbflow 0.0.15 adds update offers to the web UI and reloads open tabs
after a server restart.

## What changed

- On macOS, bbflow checks for a new release at startup and every 24 hours.
  When an update is available, open the offer in the sidebar. Review the
  sessions that will stop. Select **Update and restart** to install the update.
  Turn off **Check for a new version every day** in **Settings** to disable
  the check. [Update from the web UI](https://github.com/gyson/bbflow/blob/v0.0.15/docs/SPEC.md#update-from-the-web-ui)
- The server reuses its last port when available. When the server returns
  on that port after a restart or update, open tabs reload at the same page.
  Tabs with unsaved edits keep them and ask you to reload.
- Each session remembers its workspace pane view within the current browser
  tab. New sessions start with the pane closed.
  [Workspace pane](https://github.com/gyson/bbflow/blob/v0.0.15/docs/SPEC.md#workspace-pane)
- The sidebar shows the `draft` status in lowercase.

## Upgrade from 0.0.14

Run `bbflow update` from a terminal outside bbflow. If the server is running,
the command asks before it restarts the server and ends its active sessions.
If the server is stopped, run `bbflow server start` after the update.
Run `bbflow ui` to open the upgraded UI. The first start assigns a port.
Later starts reuse that port when available.

The first start upgrades SQLite format 10 to format 12. It preserves history,
settings, and drafts. Use the web UI to install later releases.
[Update command](https://github.com/gyson/bbflow/blob/v0.0.15/docs/COMMANDS.md#update-bbflow)

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
