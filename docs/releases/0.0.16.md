bbflow 0.0.16 adds session families and lets you choose the server port.

## What changed

- Use **New sub-session** in a session row menu to group related work. Start
  the sub-session in the parent workspace or in a new worktree. Each session
  keeps its own terminal and history.
  [Session families](https://github.com/gyson/bbflow/blob/v0.0.16/docs/SPEC.md#session-families)
- Open the row menu to archive a draft or finished session. Use **Archived**
  at the bottom of the sidebar to find and restore archived sessions.
  [Web client](https://github.com/gyson/bbflow/blob/v0.0.16/docs/SPEC.md#web-client)
- Set **Port** in **Settings** to choose the port for the next server start.
  The server keeps the automatic port setting by default. `bbflow ui` and
  **Open UI** now use `localhost` in the address.
  [Port setting](https://github.com/gyson/bbflow/blob/v0.0.16/docs/COMMANDS.md#manage-settings)
- Markdown **Preview** uses higher contrast and adds syntax colors to fenced
  code blocks for supported languages.
  [Changes and Files views](https://github.com/gyson/bbflow/blob/v0.0.16/docs/SPEC.md#changes-pane)

## Upgrade from 0.0.15

When the sidebar offers the update, open the offer and review the sessions that
will stop. Select **Update and restart** to install the release and restart the
server. You can also run `bbflow update` from a terminal outside bbflow.
[Update from the web UI](https://github.com/gyson/bbflow/blob/v0.0.16/docs/SPEC.md#update-from-the-web-ui)

The first start upgrades SQLite format 12 to format 14. It preserves history,
settings, and drafts.

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
