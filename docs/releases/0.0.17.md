bbflow 0.0.17 shows commits and images in the workspace pane, adds a custom
title tool, and makes the web UI simpler.

## What changed

- The Changes pane shows the diff of one commit, a range of commits, the
  uncommitted changes, or all changes since the session base. A scope button
  and a timeline menu replace the **Compare with** menu.
  [Changes pane](https://github.com/gyson/bbflow/blob/v0.0.17/docs/SPEC.md#changes-pane)
- The Files and Changes views show PNG, JPEG, GIF, WebP, and SVG files as
  images. An image diff shows the old and the new image together.
  [Images](https://github.com/gyson/bbflow/blob/v0.0.17/docs/SPEC.md#images)
- A ⋯ file menu in the Files and Changes views has **Copy path**, **Copy
  relative path**, **Show in Finder**, and **Open in browser**. **Open in
  browser** is available for `.html` and `.htm` files.
  [File menu](https://github.com/gyson/bbflow/blob/v0.0.17/docs/SPEC.md#file-menu)
- Each title tool now runs a test before it saves. A failed test saves nothing.
  Select **Custom** to use your own title command. On macOS 27, select
  **Apple** to make titles with the on-device Apple model.
  [Session titles](https://github.com/gyson/bbflow/blob/v0.0.17/docs/SPEC.md#session-titles)
- The Settings page shows which entries are not saved. **Remove** asks before
  it removes a tool. The page does not add two tools with the same name.
  [Saves in Settings](https://github.com/gyson/bbflow/blob/v0.0.17/docs/SPEC.md#saves-in-settings)
- The web UI has fewer labels and help texts, and the terminal has more height.
  Press Command-Enter or Ctrl+Enter to send a message. Each message shows next
  to its subject, not in one banner at the top of the page.
  [Web client](https://github.com/gyson/bbflow/blob/v0.0.17/docs/SPEC.md#web-client)
- The session terminal keeps a usable width in a narrow window. Narrow
  terminals keep more scrollback rows, so they keep about the same text as wide
  terminals.
  [Terminal scrollback](https://github.com/gyson/bbflow/blob/v0.0.17/docs/SPEC.md#terminal-scrollback)
- A session shows as `idle` after 10 seconds without output, not 3 seconds.
  Each sidebar group shows 5 session families, not 10.

## Command changes

- `bbflow title-tool list|show|set|test` replaces the `title-tool` key of
  `bbflow settings set`.
  [Title tool](https://github.com/gyson/bbflow/blob/v0.0.17/docs/COMMANDS.md#title-tool)
- `bbflow settings set` prints the saved value. `bbflow settings get KEY`
  prints one value in the form that `set` accepts. `worktree` and
  `update-check` accept only `true` and `false`.
  [Manage settings](https://github.com/gyson/bbflow/blob/v0.0.17/docs/COMMANDS.md#manage-settings)
- `bbflow tool list` prints one tool on each line: the name, a tab, and the
  command.

## Upgrade from 0.0.16

When the sidebar offers the update, open the offer and review the sessions that
will stop. Select **Update and restart** to install the release and restart the
server. You can also run `bbflow update` from a terminal outside bbflow.
[Update from the web UI](https://github.com/gyson/bbflow/blob/v0.0.17/docs/SPEC.md#update-from-the-web-ui)

The first start upgrades SQLite format 14 to format 15. It preserves history,
settings, drafts, and the selected title tool.

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
