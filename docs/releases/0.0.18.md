bbflow 0.0.18 works in phone-sized and narrow windows, and adds optional remote
access through Tailscale Serve.

## What changed

- The web UI works in a narrow window. When the main area cannot hold the
  session and the workspace pane, a **Session / Changes / Files / Terminal**
  switch shows one of them at a time.
  [View switch](https://github.com/gyson/bbflow/blob/v0.0.18/docs/SPEC.md#view-switch)
- In a window 700 px wide or less, the sidebar is a drawer and the toolbar has
  one row. **Stop session** and **Continue in new terminal** move into the ⋯
  More actions menu.
  [Mobile layout](https://github.com/gyson/bbflow/blob/v0.0.18/docs/SPEC.md#mobile-layout)
- A narrow Changes or Files view shows the file list first. Click a file to
  show it at the full width, and click **← Back** to return to the list.
  [File list in a narrow pane](https://github.com/gyson/bbflow/blob/v0.0.18/docs/SPEC.md#file-list-in-a-narrow-pane)
- A browser on another device, such as a phone, can open the web UI through
  Tailscale Serve. Remote access is off by default. Set the Tailscale host and
  your Tailscale login in **Settings** to turn it on. The server still listens
  only on loopback.
  [Remote access with Tailscale Serve](https://github.com/gyson/bbflow/blob/v0.0.18/docs/REMOTE.md)
- The More actions menu of an ended session no longer has **Reload output**.
  Click the session in the sidebar or refresh the tab to load its saved screen
  again.

## Command changes

- `bbflow settings get|set` has the keys `remote-host` and `remote-login`.
  [Manage settings](https://github.com/gyson/bbflow/blob/v0.0.18/docs/COMMANDS.md#manage-settings)

## Upgrade from 0.0.17

When the sidebar offers the update, open the offer and review the sessions that
will stop. Select **Update and restart** to install the release and restart the
server. You can also run `bbflow update` from a terminal outside bbflow.
[Update from the web UI](https://github.com/gyson/bbflow/blob/v0.0.18/docs/SPEC.md#update-from-the-web-ui)

The first start upgrades SQLite format 15 to format 16. It preserves history and
settings. Remote access stays off after the upgrade.

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
