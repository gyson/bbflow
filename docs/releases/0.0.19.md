bbflow 0.0.19 fixes a resize loop between two views of one session, and improves
bbflow as a Home Screen web app on iOS.

## What changed

- A session that is open in two views of different sizes, such as a desktop and
  a phone, no longer flashes without end. A frame no longer makes a view send a
  focus report as input.
  [Frames](https://github.com/gyson/bbflow/blob/v0.0.19/docs/SPEC.md#frames)
- Only user input moves the terminal size to a view. User input is typed keys,
  a paste, or a message. A click, a pointer move, or a focus change in a view no
  longer resizes the terminal for all views.
  [Size owner](https://github.com/gyson/bbflow/blob/v0.0.19/docs/SPEC.md#size-owner)
- When you add the web UI to the iOS Home Screen, the icon shows the bbflow
  logo. If you added bbflow before this release, remove the icon and add the
  page again. iOS does not refresh a saved icon.
  [Page and connection](https://github.com/gyson/bbflow/blob/v0.0.19/docs/SPEC.md#page-and-connection)
- In the mobile layout, the toolbar stays at the top of the main area and has an
  opaque background. The session title is now sharp in a Home Screen web app on
  iOS.
  [Toolbar in the mobile layout](https://github.com/gyson/bbflow/blob/v0.0.19/docs/SPEC.md#toolbar-in-the-mobile-layout)
- The README is shorter and shows a screenshot. A new user guide explains tools,
  projects, sessions, the handoff between agents, search, and remote access.
  [User guide](https://github.com/gyson/bbflow/blob/v0.0.19/docs/GUIDE.md)

## Upgrade from 0.0.18

When the sidebar offers the update, open the offer and review the sessions that
will stop. Select **Update and restart** to install the release and restart the
server. You can also run `bbflow update` from a terminal outside bbflow.
[Update from the web UI](https://github.com/gyson/bbflow/blob/v0.0.19/docs/SPEC.md#update-from-the-web-ui)

This release keeps SQLite format 16. Open tabs reload once after the restart to
load the new UI.

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
