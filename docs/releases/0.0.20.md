bbflow 0.0.20 adds built-in agent tools with a choice of model and thinking
effort, steps between sent messages in the terminal, and touch scroll on phones.

## What changed

- Settings → Tools has built-in tools for Codex, Claude Code, Antigravity, Code
  Puppy, and Shell. Each tool has an On/Off switch. A tool that is off is not a
  choice in the tool menus. Click **＋ Add custom tool** to add another command.
  [Built-in tools](https://github.com/gyson/bbflow/blob/v0.0.20/docs/SPEC.md#built-in-tools)
- Each built-in agent tool has a default model and a default thinking effort. A
  draft can choose another model and effort for one session. bbflow reads the
  model lists from the Codex, Antigravity, and Code Puppy CLIs. **Other…**
  accepts any model name.
  [Tool types and models](https://github.com/gyson/bbflow/blob/v0.0.20/docs/SPEC.md#tool-types-and-models)
- The Claude, Codex, and Code Puppy title tools can choose a model and a
  thinking effort. The choice saves only after a passed title test.
  [Title models](https://github.com/gyson/bbflow/blob/v0.0.20/docs/SPEC.md#title-models)
- The bar above the session terminal names the sent message that you read.
  **Earlier message** and **Later message** scroll the terminal from message to
  message. In the terminal, Command+Up and Command+Down do the same.
  [Go to a sent message](https://github.com/gyson/bbflow/blob/v0.0.20/docs/GUIDE.md#go-to-a-sent-message)
- The list of sent messages is now the **Messages** view of the workspace pane.
  It replaces the **Sent messages** dialog. **Show in terminal** scrolls the
  terminal to a message.
  [Sent messages](https://github.com/gyson/bbflow/blob/v0.0.20/docs/SPEC.md#sent-messages)
- A vertical drag with a finger scrolls a terminal on a touch screen, such as a
  phone.
  [Touch scroll in a terminal](https://github.com/gyson/bbflow/blob/v0.0.20/docs/SPEC.md#touch-scroll-in-a-terminal)
- On a phone, the page stays above the on-screen keyboard, and the toolbar stays
  at the top. Text fields no longer make Safari zoom. In the mobile layout, the
  message editor has the height of its text, so the terminal shows more rows.
  [On-screen keyboard](https://github.com/gyson/bbflow/blob/v0.0.20/docs/SPEC.md#on-screen-keyboard)
- **Stop session** is now the last item of the ⋯ More actions menu, also on
  desktop. A missed click on a toolbar icon can no longer end a session.
  [More actions menu](https://github.com/gyson/bbflow/blob/v0.0.20/docs/SPEC.md#more-actions-menu)
- Remote access has its own On/Off switch in Settings. Turning it off keeps the
  Tailscale host name and login. Each field saves on Enter or when it loses
  focus, and the card has no Save button.
  [Turn remote access off](https://github.com/gyson/bbflow/blob/v0.0.20/docs/REMOTE.md#turn-remote-access-off)
- bbflow no longer creates a General project. A new instance starts with no
  projects. Every project can be renamed and removed.
  [Projects](https://github.com/gyson/bbflow/blob/v0.0.20/docs/SPEC.md#projects)

## Command changes

- `bbflow tool enable NAME` and `bbflow tool disable NAME` turn a tool on or
  off. `tool list` prints `on` or `off` in a third column. `tool add` refuses
  the name of a built-in tool.
  [Manage tools](https://github.com/gyson/bbflow/blob/v0.0.20/docs/COMMANDS.md#manage-tools)
- `bbflow settings get|set` has the keys `shell` and `remote`. After a save of
  `remote`, `remote-host`, or `remote-login`, the command prints the status of
  remote access.
  [Manage settings](https://github.com/gyson/bbflow/blob/v0.0.20/docs/COMMANDS.md#manage-settings)
- `bbflow title-tool set TOOL` accepts `--model MODEL` and `--effort EFFORT`.
  [Title tool](https://github.com/gyson/bbflow/blob/v0.0.20/docs/COMMANDS.md#title-tool)

## Upgrade from 0.0.19

When the sidebar offers the update, open the offer and review the sessions that
will stop. Select **Update and restart** to install the release and restart the
server. You can also run `bbflow update` from a terminal outside bbflow.
[Update from the web UI](https://github.com/gyson/bbflow/blob/v0.0.20/docs/SPEC.md#update-from-the-web-ui)

The first start upgrades SQLite format 16 to format 18. It preserves history and
settings. Open tabs reload once after the restart to load the new UI.

- A saved tool with the command of a built-in tool becomes that built-in tool.
  It keeps its ID and name. The other saved tools become custom tools. Each tool
  submits the same command as before.
- After the upgrade, the server turns on each built-in tool whose CLI it finds.
- Remote access stays on where the Tailscale host name and login were both
  saved.
- A General project from an earlier release stays as an ordinary project. You
  can rename or remove it.
  [Formats](https://github.com/gyson/bbflow/blob/v0.0.20/docs/SPEC.md#formats)

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
