bbflow 0.0.21 adds pinned sessions at the top of the sidebar, fits an ended
terminal to its view, and opens a live session without extra PTY resizes.

## What changed

- **Pin** in the ⋯ row menu of a session moves the session and its sub-sessions
  to **Pinned** at the top of the sidebar, above all projects. **Pin** and
  **Unpin** are also in the More actions menu of the toolbar. The newest pin
  comes first, and each pinned session shows the name of its project. At most 20
  sessions can have a pin. Archive removes the pin.
  [Pin a session](https://github.com/gyson/bbflow/blob/v0.0.21/docs/GUIDE.md#pin-a-session)
  and
  [Pinned sessions](https://github.com/gyson/bbflow/blob/v0.0.21/docs/SPEC.md#pinned-sessions)
- On a large screen, the default sidebar width grows with the window: 278 pixels
  up to a 1390 pixel window, then 20 percent of the window, up to 360 pixels.
  Smaller windows keep the earlier widths. In windows from 1465 to 1483 pixels
  wide, an open pane now uses the view switch instead of showing beside the
  session.
  [Sidebar width](https://github.com/gyson/bbflow/blob/v0.0.21/docs/SPEC.md#sidebar-width)
- An ended terminal fills the terminal area in every view, also after each size
  change. It keeps the recorded width. The last row with text is the last row of
  the view, and a taller view shows history rows above it. Before, an ended
  terminal kept the size of the PTY when its process ended, for example 9 rows
  at the top of a large area. A live view of another size than the terminal
  shows the saved screen when the process ends, as a reload shows it.
  [Display of an ended session](https://github.com/gyson/bbflow/blob/v0.0.21/docs/SPEC.md#display-of-an-ended-session)
- A live session view opens at its final size. In a wide desktop window, the
  request that opens the view has the final size, and the view sends no later
  `resize`. In a narrow window, a session with more than one terminal can get
  one `resize`. Before, each open resized the PTY up to three times, so a
  full-screen agent could redraw up to three times. The terminal area of a live
  view shows no scroll bar, but it still scrolls.
  [Size of a session view](https://github.com/gyson/bbflow/blob/v0.0.21/docs/SPEC.md#size-of-a-session-view)

## Command changes

- `bbflow query` can read the new `sessions.pinned_at` column. It holds the time
  of the pin, or NULL for a session without a pin. `bbflow skill` describes it.

## Upgrade from 0.0.20

When the sidebar offers the update, open the offer and review the sessions that
will stop. Select **Update and restart** to install the release and restart the
server. You can also run `bbflow update` from a terminal outside bbflow.
[Update from the web UI](https://github.com/gyson/bbflow/blob/v0.0.21/docs/SPEC.md#update-from-the-web-ui)

The first start upgrades SQLite format 18 to format 19. It preserves history and
settings. No session has a pin after the upgrade. Open tabs reload once after
the restart to load the new UI.
[Formats](https://github.com/gyson/bbflow/blob/v0.0.21/docs/SPEC.md#formats)

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
