bbflow 0.0.22 lets the Messages view jump to a message in another terminal of
the session.

## What changed

- In a session with several terminals, **Show in terminal** in the **Messages**
  view can open another terminal of the session and scroll it to the message.
  The button names that terminal, for example **Show in terminal 1**. An
  earlier terminal shows its saved final screen, with input and **Send** off.
  **Back to live terminal** returns. Before, the button was off for a message
  of another terminal.
  [Go to a sent message](https://github.com/gyson/bbflow/blob/v0.0.22/docs/GUIDE.md#go-to-a-sent-message)
  and
  [Jump to another terminal](https://github.com/gyson/bbflow/blob/v0.0.22/docs/SPEC.md#jump-to-another-terminal)
- In a session with more than one terminal, the **Messages** list shows a
  heading above the messages of each terminal. The heading of the shown
  terminal has the label **Shown**. The list keeps its messages and its position
  when the shown terminal changes.
- When the opened terminal does not show the message, or a read of the sent
  messages fails, an error toast says so.
- When another view starts or ends a terminal of the session, the headings and
  the buttons name the new terminal without a reload. A failed read of the
  terminal list keeps the terminal selector.
- **Earlier message**, **Later message**, and the step keys still stay in the
  shown terminal.

## Upgrade from 0.0.21

When the sidebar offers the update, open the offer and review the sessions that
will stop. Select **Update and restart** to install the release and restart the
server. You can also run `bbflow update` from a terminal outside bbflow.
[Update from the web UI](https://github.com/gyson/bbflow/blob/v0.0.22/docs/SPEC.md#update-from-the-web-ui)

This release keeps SQLite format 19. Open tabs reload once after the restart to
load the new UI.

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
