bbflow 0.0.23 adds saved prompts to a new ＋ menu of the message editor, opens a
menu from the ⋯ button of a project, and keeps an idle agent idle in the sidebar.

## What changed

- **＋** in the message editor now opens the **Add to message** menu. It replaces
  the **＋ Attach files** and **Handoff prompt** buttons. The menu has **Attach
  files…**, **Handoff prompt…**, one item for each saved prompt, and **Manage
  prompts…**. A saved prompt goes in at the cursor, or in place of the selected
  text. The insert saves as a draft and sends nothing.
  [Use a saved prompt](https://github.com/gyson/bbflow/blob/v0.0.23/docs/GUIDE.md#use-a-saved-prompt)
  and
  [Add to message menu](https://github.com/gyson/bbflow/blob/v0.0.23/docs/SPEC.md#add-to-message-menu)
- The new **Prompts** card in Settings adds, edits, sorts, and removes saved
  prompts. Saved prompts are global, so every session, view, and device shows the
  same list. At most 100 prompts can be saved, each with at most 16 KiB of text.
  [Saved prompts](https://github.com/gyson/bbflow/blob/v0.0.23/docs/SPEC.md#saved-prompts)
- In the handoff prompt dialog, **Put in message editor** is now **Insert in
  message**. It inserts the prompt at the cursor, so the message editor no longer
  has to be empty.
  [Handoff prompt](https://github.com/gyson/bbflow/blob/v0.0.23/docs/SPEC.md#handoff-prompt)
- The ⋯ button of a project now opens a menu with **Edit**, **Copy folder path**,
  **Search this project**, and **Remove project**. Before, it opened a dialog in
  which **Remove project** removed the project at once. Now **Remove project**
  asks first, and a removal keeps the current view, such as Settings or the
  selected session. **Edit** changes only the name.
  [Change or remove a project](https://github.com/gyson/bbflow/blob/v0.0.23/docs/GUIDE.md#change-or-remove-a-project)
  and
  [Project menu](https://github.com/gyson/bbflow/blob/v0.0.23/docs/SPEC.md#project-menu)
- An open row menu now stays above the ⋯ buttons of later rows. Before, those
  buttons covered parts of the menu and took its clicks. In every menu, Up and
  Down now skip the items that are off.
- An agent that waits at its prompt now stays **Idle**. Only output that changes
  the screen is activity. Before, an idle Codex showed **Running** for 10 seconds
  about every 15 seconds, and a bell of Claude Code gave a 10-second **Running**
  flash. Output that really changes the screen, such as a recap line of Claude
  Code, still shows **Running**.
  [Activity detection](https://github.com/gyson/bbflow/blob/v0.0.23/docs/SPEC.md#activity-detection)
- A session no longer moves in the sidebar while nobody uses it. The order skips
  output that changes nothing, the focus and mouse reports of a view, and the
  redraw after a resize. Typed input, sent messages, and real output still move a
  session.
  [Session list order](https://github.com/gyson/bbflow/blob/v0.0.23/docs/SPEC.md#session-list-order)
- The status tooltip now says **Running: a screen change in the last 10 seconds**
  and **Idle: live, with no screen change in the last 10 seconds**.

## Command changes

- `bbflow query` can read the new `events.quiet` column. It is `1` for an `input`
  or `output` event that is not session activity, else `0`. The server sets the
  flag of an `output` event just after it records the output, so a query can see
  `0` for a short time. `bbflow skill` describes it.
- The `settings.data` JSON has the new `prompts` list. Each saved prompt has an
  `id`, a `name`, and its `text`. `bbflow skill` describes it.

## Upgrade from 0.0.22

When the sidebar offers the update, open the offer and review the sessions that
will stop. Select **Update and restart** to install the release and restart the
server. You can also run `bbflow update` from a terminal outside bbflow.
[Update from the web UI](https://github.com/gyson/bbflow/blob/v0.0.23/docs/SPEC.md#update-from-the-web-ui)

The first start upgrades SQLite format 19 to format 21. It preserves history and
settings. The list of saved prompts starts empty. Events from before the upgrade
are not quiet, so existing sessions keep their sidebar order until they have new
activity. Open tabs reload once after the restart to load the new UI.
[Formats](https://github.com/gyson/bbflow/blob/v0.0.23/docs/SPEC.md#formats)

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
