bbflow 0.0.24 adds a **Usage** dialog with the usage limits of Codex, Claude Code,
and Antigravity. **Continue in new terminal** now selects the tool of the latest
terminal and lets you choose its model and thinking effort.

## What changed

- **Usage** in the bottom row of the sidebar opens a dialog with the usage limits
  of your agent plans. It has a section for Codex, Claude Code, and Antigravity
  when their tools are on. Each limit shows the part that is left and its reset
  time, such as **62% left** and **Resets 6:32 AM · in 3 h 52 min**. A limit with
  less than 20% left is amber, and an empty limit is red.
  [Check your usage limits](https://github.com/gyson/bbflow/blob/v0.0.24/docs/GUIDE.md#check-your-usage-limits)
  and
  [Usage limits](https://github.com/gyson/bbflow/blob/v0.0.24/docs/SPEC.md#usage-limits)
- The server asks each agent CLI for the limits of your account. A check starts
  no agent turn and sends no history. The server reuses a check for 1 minute.
  **Check now** asks each CLI again. A failed check shows its error. If an earlier
  check succeeded, the dialog keeps its values with a warning.
- The checks run the **CLI path** of each built-in tool. The **CLI path** help in
  Settings now names the usage check. If a section shows an error, sign in to the
  agent in a terminal, or set its **CLI path**.
- **Usage** sits between **Archived** and **Settings**. In a narrow sidebar,
  **Usage** and **Settings** wrap together to a second line.
- The **Continue in new terminal** dialog now has the **Tool**, **Model**, and
  **Thinking effort** fields of a new session draft. A newly selected tool brings
  its default model and effort. **Other…** takes any model name. Before, a new
  terminal always used the default model and effort of the tool.
  [Continue with a different agent](https://github.com/gyson/bbflow/blob/v0.0.24/docs/GUIDE.md#continue-with-a-different-agent)
  and
  [Continue in a new terminal](https://github.com/gyson/bbflow/blob/v0.0.24/docs/SPEC.md#continue-in-a-new-terminal)
- The dialog now selects the tool of the latest terminal. Before, it selected the
  tool that the session started with. For example, a session that went from Codex
  to Claude Code now continues with Claude Code. If that tool is no longer a
  choice, the dialog selects the tool that the session started with, then the
  default tool, then Shell.

## Command changes

- `bbflow query` can read the new `toolId` key in the JSON of a `start` event. It
  is the ID of the tool in Settings, and it is empty for Shell. `bbflow skill`
  describes it. It now also describes the `continues` and `handoff` keys, which
  earlier releases recorded without documentation.

## Upgrade from 0.0.23

When the sidebar offers the update, open the offer and review the sessions that
will stop. Select **Update and restart** to install the release and restart the
server. You can also run `bbflow update` from a terminal outside bbflow.
[Update from the web UI](https://github.com/gyson/bbflow/blob/v0.0.24/docs/SPEC.md#update-from-the-web-ui)

This release keeps SQLite format 21. Start events from before the upgrade have no
`toolId`. The first terminal of a session takes the tool ID of its draft. If the
latest terminal is a later terminal from before the upgrade, the Continue dialog
selects the tool that the session started with. Open tabs reload once after the
restart to load the new UI.

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
