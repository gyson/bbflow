bbflow 0.0.25 keeps the picture of a live session terminal when its size changes.
The terminal also fits its area exactly, so one size change makes one resize.

## What changed

- A size change of a live session terminal no longer shows an empty terminal.
  This applies when you open or close the side terminal, resize the window, or
  drag the terminal or workspace divider. The terminal keeps its old picture
  until the frame of the new size arrives. Then it shows the new frame in one
  step. Before, each size change showed an empty terminal, for up to 0.4 seconds
  in a session with long history. A drag of a divider flickered many times.
  [Size of a session view](https://github.com/gyson/bbflow/blob/v0.0.25/docs/SPEC.md#size-of-a-session-view)
- The view that sets the terminal size now gets one frame for each resize, at
  its new size. Before, it got two frames, and the first frame showed the old
  screen cut to the new size. The same rule applies to a view that joins with
  another size, and to a view that takes the size after the earlier view
  closes.
  [Frames and reattachment](https://github.com/gyson/bbflow/blob/v0.0.25/docs/SPEC.md#frames-and-reattachment)
- A fit now gives the largest number of columns and rows that the terminal can
  draw in its area. Before, a fit was often one column off. A second resize
  followed, and the agent drew its screen again. At a display scale of 1.5 or
  2, some window heights made the terminal switch between two row counts
  without end. The side terminal uses the same fit.

## Upgrade from 0.0.24

When the sidebar offers the update, open the offer and review the sessions that
will stop. Select **Update and restart** to install the release and restart the
server. You can also run `bbflow update` from a terminal outside bbflow.
[Update from the web UI](https://github.com/gyson/bbflow/blob/v0.0.25/docs/SPEC.md#update-from-the-web-ui)

This release keeps SQLite format 21. Open tabs reload once after the restart to
load the new UI.

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
