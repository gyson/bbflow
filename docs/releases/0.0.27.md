bbflow 0.0.27 shows the live sessions on Home, groups the saved prompts of the ＋ menu,
and removes text from the UI that repeats what the layout shows.

## What changed

- Home now lists every session with a live terminal, from all projects, in the
  groups **Running** and **Idle**. A row shows the title, the project, the tool of the
  latest terminal, a worktree mark, and the parent of a sub-session. It also shows the
  latest sent message with its age, and **Unsent message** when the saved draft has
  text or attachments. An idle row shows the time since the latest activity. A click
  opens the session. **＋ New session** above the groups opens a menu with one item for
  each project. Without a project, Home shows **＋ Project** instead. In the mobile
  layout, the drawer now stays closed on Home.
  [See the live sessions on Home](https://github.com/gyson/bbflow/blob/v0.0.27/docs/GUIDE.md#see-the-live-sessions-on-home)
  and
  [Home](https://github.com/gyson/bbflow/blob/v0.0.27/docs/SPEC.md#home)
- Saved prompts can now belong to a group. The ＋ menu of the message editor shows the
  prompts without a group first, then one row for each group. On a wide screen, a
  group opens a flyout with its prompts. On a narrow screen, such as a phone, a tap on
  a group shows its prompts in the menu, and **‹ Group name** goes back. In Settings,
  **Prompts** shows a **Top level** block and one block for each group, with **＋ Add
  prompt**, **Rename**, **↑**, **↓**, and **Remove**. The prompt editor has a **Group**
  select with **New group…**. **Remove** of a group asks whether to move its prompts or
  remove them too.
  [Group your saved prompts](https://github.com/gyson/bbflow/blob/v0.0.27/docs/GUIDE.md#group-your-saved-prompts)
  and
  [Saved prompts](https://github.com/gyson/bbflow/blob/v0.0.27/docs/SPEC.md#saved-prompts)
- **Usage** in the sidebar now shows only when Codex, Claude Code, or Antigravity is
  on. A change in Settings shows or hides it at once.
  [Check your usage limits](https://github.com/gyson/bbflow/blob/v0.0.27/docs/GUIDE.md#check-your-usage-limits)
- The UI has less secondary text. Switches no longer show **On** or **Off** beside
  them. Settings no longer has help lines under the fields, the model and option
  notes of the tool editor, or the text about Enter and Esc. The Changes pane has no
  file count, a confirmed message has no **SENT** badge, and the side terminal shows no
  size. The Search history dialog has no scope label. Its **Search in** menu now shows
  the project name instead of **This project**. Warnings about risks and limits stay.
  `docs/GUIDE.md` and `docs/REMOTE.md` now explain the removed facts that a user can
  need.

## Command changes

- `bbflow query` can read the new `promptGroups` list and the `group` key of each
  saved prompt in `settings.data`. `bbflow skill` describes both.
- The server rejects settings with an unknown prompt group, duplicate group IDs, or
  duplicate group names. The settings hold at most 50 groups.

## Upgrade from 0.0.26

Open **Settings** and use the **Updates** card to install the release and restart the
server. You can also run `bbflow update` from a terminal outside bbflow. The restart
stops all sessions.
[Update from the web UI](https://github.com/gyson/bbflow/blob/v0.0.27/docs/SPEC.md#update-from-the-web-ui)

The first start upgrades SQLite format 22 to format 23. It preserves history and
settings. Each saved prompt stays at the top level of the ＋ menu, in the same order.
Open tabs reload once after the restart to load the new UI.
[Formats](https://github.com/gyson/bbflow/blob/v0.0.27/docs/SPEC.md#formats)

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
