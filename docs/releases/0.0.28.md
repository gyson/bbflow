bbflow 0.0.28 can start Claude Code in its experimental Code Mode, and makes the
sidebar row menus work on iPhone Safari.

## What changed

- The built-in Claude Code tool has a new **Code Mode** menu with **CLI default** and
  **On**. In Code Mode, Claude writes JavaScript that calls several tools in one step.
  The Claude Code tool editor in Settings has **Default Code Mode**. A draft and the
  **Continue in new terminal** dialog have **Code Mode**. A newly selected tool brings
  its default. **On** puts `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1` before the command.
  **CLI default** starts Claude Code as before. The first time, Claude Code asks you to
  confirm in the terminal. The menu is hidden for all other tools. The shell must
  accept `NAME=value command`. Choose **CLI default** with csh or tcsh.
  [Add your tools](https://github.com/gyson/bbflow/blob/v0.0.28/docs/GUIDE.md#add-your-tools)
  and
  [Code Mode](https://github.com/gyson/bbflow/blob/v0.0.28/docs/SPEC.md#code-mode)
- On iPhone Safari, a tap on an item of a sidebar ⋯ menu now runs the item. Before,
  **Stop session**, **Stop family**, **Pin**, **Archive**, and the items of the project
  menu only closed the menu. A tap outside the menu, Escape, and a focus move to
  another control still close it.
  [Archive action](https://github.com/gyson/bbflow/blob/v0.0.28/docs/SPEC.md#archive-action)

## Command changes

- `bbflow query` can read the new `codeMode` key of each tool in `settings.data` and
  in `preparations.data`. `bbflow skill` describes both.
- The server rejects Code Mode for a tool that is not Claude Code, including Custom,
  Shell, and title tools.

## Upgrade from 0.0.27

Open **Settings** and use the **Updates** card to install the release and restart the
server. You can also run `bbflow update` from a terminal outside bbflow. The restart
stops all sessions.
[Update from the web UI](https://github.com/gyson/bbflow/blob/v0.0.28/docs/SPEC.md#update-from-the-web-ui)

The first start upgrades SQLite format 23 to format 24. It preserves history and
settings. Each saved tool and draft gets **CLI default**, so its command stays the same.
Open tabs reload once after the restart to load the new UI.
[Formats](https://github.com/gyson/bbflow/blob/v0.0.28/docs/SPEC.md#formats)

## New installation

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bbflow server start
bbflow ui
```
