BonBon 0.0.6 lets you search recorded terminal output, review earlier terminals, and
see Git changes from the session workspace.

## What changed

- **Search history** finds text in recorded terminal output across a session, a
  project, or all sessions. Each scope includes archived sessions. Select a match to
  read and copy surrounding output. On macOS, press Command+Shift+F to open the dialog.
  Search covers derived output, including text that has left the terminal scrollback.
  Redraws can repeat text. Search excludes input, unsent drafts, and attachment contents.
- The terminal selector shows each terminal's tool, status, and start and end times.
  Select an earlier terminal to see its saved final screen in a read-only view. The live
  terminal keeps running while you review the earlier screen.
- **Changes** shows Git changes for the session workspace in a read-only pane. Choose a
  split or unified diff, or open the current file. In a managed worktree, the default
  comparison includes changes since its recorded base commit. Use **Refresh** to read
  the latest changes.
- **Appearance** in Settings offers **System**, **Light**, and **Dark**. System follows
  the device appearance. **Save settings** stores the choice for the BonBon instance.
- `bonbon skill` prints an embedded guide for agents. It explains how to use
  `bonbon query` to read sessions and history.
- The macOS menu shows the running version in **Quit BonBon (0.0.6)**.

## Upgrade from 0.0.5

Run `bonbon update` to replace the executable. The running server and sessions continue.
When you are ready to end active terminals, run:

```sh
bonbon server restart
bonbon ui
```

The server upgrades SQLite formats 3–7 to format 8 on startup. The upgrade adds indexes
for terminal history and sets the default appearance to System. It preserves recorded
events, sessions, and drafts. BonBon does not support database downgrades.

The new server uses protocol `bonbon/21`. Close tabs from 0.0.5 and use the tab that
`bonbon ui` opens after the restart.

## Install

```sh
curl -fsSL https://github.com/gyson/bonbon/releases/latest/download/install.sh | sh
```

The installer selects the Apple Silicon or Intel archive, verifies its checksum and
version, and installs to `~/.local/bin`. Run `bonbon server start` and `bonbon ui` to
open BonBon.

## Release checks

The Release workflow runs `make test`, `make check`, `make web-check`, and a native
release smoke check on Apple Silicon and Intel before it publishes the archives.
Migration tests cover upgrades from formats 3–7, data preservation, rollback, and
concurrent opens.
A local smoke check upgraded a synthetic format 6 database and verified that its
original event records stayed intact.
