BonBon 0.0.7 adds a workspace pane with a file tree and a side terminal.
The sidebar and session toolbar show recent terminal activity.

## What changed

- **Show changes** opens the Git diff view. Choose a baseline and a split or unified
  diff. From **Files**, use **View diff** to open the diff for a changed file.
- **Show files** opens a folder tree, including in workspaces without Git. Select a
  file to read its current contents. In a Git workspace, browse ignored files in the
  tree or use the path filter to find files that Git does not ignore.
- **Show terminal** opens a shell in the session workspace. All tabs for a session
  share the same side terminal. Closing its view or using **Stop session** leaves
  the shell running. Use **Stop shell** to end it. BonBon does not record the side
  terminal or use it to set the session status.
- Each session has one status: `draft`, `running`, `idle`, or `ended`. A live session
  moves to `idle` after 3 seconds without application output. An idle agent can
  still be working, waiting for input, or finished.
- The session toolbar has icons with tooltips. Use **More actions** (⋯) for actions
  such as **Rename** and **Archive**.

## Upgrade from 0.0.6

Run `bonbon update` to replace the executable. The running server and its terminals
continue until you restart the server. When you are ready to stop them, run:

```sh
bonbon server restart
bonbon ui
```

The new server uses protocol `bonbon/24`. Close old BonBon tabs and use the tab that
`bonbon ui` opens. The SQLite format stays at 8. Existing sessions, recordings,
settings, and drafts remain available.

## Install

```sh
curl -fsSL https://github.com/gyson/bonbon/releases/latest/download/install.sh | sh
```

The installer selects the Apple Silicon or Intel archive, verifies its checksum and
version, and installs to `~/.local/bin`. Run `bonbon server start` and `bonbon ui` to
open BonBon.

## Release checks

The Release workflow runs `make test`, `make check`, `make web-check`, and a native
release smoke check on Apple Silicon and Intel before it publishes the archives.
