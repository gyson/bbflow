bbflow 0.0.9 moves BonBon managed worktrees into bbflow during `bbflow migrate`. If you
already ran `bbflow migrate` with 0.0.8, run it again to move the worktrees.

## What changed

- `bbflow migrate` moves each managed worktree from `~/.bonbon/worktrees` to
  `~/.bbflow/worktrees` with `git worktree move`. Git updates its worktree records, and
  uncommitted files move with the worktree. The copied sessions use the new paths.
- If bbflow history already exists, `bbflow migrate` does not copy the BonBon history
  again. It only moves the BonBon worktrees that bbflow sessions still use. A run with
  nothing to move changes nothing.
- If Git does not move a worktree, for example a locked worktree or a worktree with
  submodules, the command reports it. That session keeps the old path.
- Moved worktrees are inside the bbflow `worktrees` directory, so **Remove worktree**
  can remove them.

After a move, BonBon cannot open those worktree sessions. The BonBon database does not
change. Other folders, such as `~/.bonbon/workspaces/general`, stay where they are.

## Upgrade from 0.0.8

Run `bbflow update` to replace the executable. Then stop the server, move the
worktrees, and start the server again:

```sh
bbflow update
bbflow server stop
bbflow migrate
bbflow server start
bbflow ui
```

`bbflow server stop` ends active bbflow sessions. The SQLite format stays at 8.
Existing sessions, recordings, settings, and drafts remain available.

## Move from BonBon 0.0.7

Install bbflow, then copy your history and move your worktrees once:

```sh
curl -fsSL https://github.com/gyson/bbflow/releases/latest/download/install.sh | sh
bonbon server stop
bbflow migrate
bbflow server start
bbflow ui
```

When you no longer need BonBon, remove the `bonbon` executable and `~/.bonbon`
yourself. Before you remove `~/.bonbon`, check the folders that `bbflow migrate` lists.
Copied sessions still use them.
