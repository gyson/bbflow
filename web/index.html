Changes

    Terminal
    MAKE IT YOURS

    Settings

    Appearance

    System follows your device appearance.

    Session defaults

    HEAD uses the project’s current commit. Uncommitted changes are not copied. Existing sessions keep their choices.

    Tools

    Shell starts without a command. Tool commands use your shell’s syntax and can include flags or wrappers. Use the normal screen to record scrollback. For Codex, add --no-alt-screen.

    NameCommand

    Automatic titles

    After the terminal accepts the first message from the message editor, bbflow asks the title tool once for a session title. A title that you set always has priority. None keeps the tool and folder name.

    Command:

    The CLI must be installed on the PATH of the server and signed in. The tool sends your first message to its provider, with paths masked and the tools of the CLI turned off. Code Puppy still runs your user plugins. Claude and Code Puppy can save each call in their own history.

    Add project

    Save a folder to prepare new sessions there. Any existing folder works; Git is optional.

    Removing a project moves its sessions to Standalone. Their history, running processes, and files are preserved.

    Rename session

    Leave the title empty to show the automatic title.
    NEW TERMINAL

    Continue in a new terminal

    bbflow starts a new terminal in this session. The session keeps its ID, workspace, message draft, and history. Before the start, bbflow writes a read-only handoff folder with the earlier terminals and your sent messages.

    Send the handoff prompt when the agent is ready. Use Handoff prompt in the message editor to open it again.

    The latest terminal was interrupted. If the server stopped unexpectedly, its agent can still run and change files in this workspace. Check this before you continue.
    MESSAGE EDITOR

    Handoff prompt

    This prompt points an agent to the handoff folder of this session. The folder has the earlier terminals and your sent messages. bbflow rebuilds it each time you continue in a new terminal. Send the prompt when the agent is ready.
    MESSAGE EDITOR

    Sent messages

    Messages that Send sent in this session. The newest message is at the bottom. Text typed directly in the terminal is not included. Copy puts the message text on the clipboard.
