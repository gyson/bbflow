      Session defaults

      HEAD is the current commit of the project. Uncommitted changes are not included. The field saves when you press Enter or leave it. Press Esc to restore the saved value.

      Automatic titles

      bbflow asks the title tool once for a title, after your first sent message. A title that you set has priority. bbflow tests a title tool before it saves it. The test can take up to 90 seconds. A title tool is separate from the tools that start sessions.

      Command:

      The command gets the request on standard input. It must print one line that starts with bbflow-title: and then the title. bbflow does not limit what a custom command can do. Prefer standard input to "$(cat)", because other programs on this Mac can read the arguments of a command.

      • Claude, Codex, and Code Puppy must be installed on the PATH of the server and signed in. They send your first message to their provider, with paths masked and the tools of the CLI turned off.
      • Claude and Code Puppy can save each call in their own history. Code Puppy still runs your user plugins.
      • Apple uses the on-device model of macOS 27 and keeps your message on this Mac. Before you use Apple, run sudo /usr/bin/fm license and accept the terms.

      Updates

      The server asks GitHub for the latest release at start and once a day. The request sends no history or settings. bbflow updates only after you confirm.

      Server

      Enter a port from 1024 to 65535, or leave the field empty for an automatic port. The field saves when you press Enter or leave it. Press Esc to restore the saved port. A new port applies after a server restart, which stops all sessions.

      Remote access

      Remote access lets you open bbflow on another device, such as a phone, through Tailscale Serve on this Mac. It works only while the switch is on and both fields are saved. A person who can use remote access can run commands on this Mac as you.

      The host name is the name of this Mac in your tailnet. The login is the account of your Tailscale devices. Tailscale Serve on this Mac must forward the host name to the port of the server.

      Each field saves when you press Enter or leave it. Press Esc to restore the saved value. The switch saves at once and keeps both fields. A change closes the open remote connections. Thus a remote view that turns the switch off cannot turn it on again.
