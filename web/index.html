    Automatic titles

    bbflow asks the title tool once for a title, after your first sent message. A title that you set has priority.

    Command:

    Claude, Codex, and Code Puppy must be installed on the PATH of the server and signed in. They send your first message to their provider, with paths masked and the tools of the CLI turned off. Code Puppy still runs your user plugins. Claude and Code Puppy can save each call in their own history. Apple uses the on-device model of macOS 27 and keeps your message on this Mac. Before you use Apple, run sudo /usr/bin/fm license and accept the terms.

    Updates

    The server asks GitHub for the latest release at start and once a day. The request sends no history or settings. bbflow updates only after you confirm.

    Server

    Enter a port from 1024 to 65535, or leave the field empty for an automatic port. A new port applies after a server restart, which stops all sessions.

    Add project

    Any existing folder works. Git is optional.

    Removing a project moves its sessions to Standalone. Their history, running processes, and files are preserved.
